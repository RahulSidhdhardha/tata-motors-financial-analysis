# Tata Motors Financial Analysis
Financial analysis of Tata Motors using key financial ratios and performance metrics for FY2023–FY2025.

## Project Overview
This project analyzes Tata Motors' financial performance using:
- Revenue
- Profit After Tax (PAT)
- EBITDA Margin
- EPS
- ROE
- Total Debt
- Total Equity
- Net Margin
- ROCE
- Debt-to-Equity Ratio
- Year-on-Year Growth

## Financial Years

- FY2023
- FY2024
- FY2025

## Tools Used

- Microsoft Excel
- Financial statement analysis
- Ratio analysis

Tata Motors Integrated Annual Reports:
- 78th Annual Report 2022–23
